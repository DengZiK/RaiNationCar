# 电机 CAN ID 与物理位置对应关系图

> 本文档描述 M3508 电机 + C620 电调的 CAN ID 分配、电调 DIP 开关设置、以及底盘物理布局的完整对应关系。

## 2. C620 电调 DIP 开关设置

每个 C620 电调上有一个 ID 设置按钮/DIP 开关，需要按上表设置为对应 ID：

```
┌──────────────────────────────────────────────────────────────────┐
│  C620 ESC ID  │  底盘电机       │  反馈 CAN ID  │  命令字节位置   │
├───────────────┼────────────────┼───────────────┼────────────────┤
│      ID 1     │  1号 右前 (FR)  │    0x201      │  0x200 [0:1]   │
│      ID 2     │  2号 左前 (FL)  │    0x202      │  0x200 [2:3]   │
│      ID 3     │  3号 左后 (RL)  │    0x203      │  0x200 [4:5]   │
│      ID 4     │  4号 右后 (RR)  │    0x204      │  0x200 [6:7]   │
│      ID 5     │  5号 升降       │    0x205      │  0x1FF [0:1]   │
└──────────────────────────────────────────────────────────────────┘

重要: 底盘电调必须设置为 ID 1~4，升降电调必须设置为 ID 5
      ID 不能重复，否则两个电调抢同一总线 → 通信冲突
```

## 3. CAN 数据帧详解

### 3.1 控制帧 (STM32 → C620)

#### 底盘 0x200 帧 (DLC=8, 标准帧)

```
┌──────────┬────────┬────────┬────────┬────────┐
│  Byte    │  0-1   │  2-3   │  4-5   │  6-7   │
├──────────┼────────┼────────┼────────┼────────┤
│  内容    │ 电机1  │ 电机2  │ 电机3  │ 电机4  │
│          │ FR 电流 │ FL 电流 │ RL 电流 │ RR 电流 │
├──────────┼────────┼────────┼────────┼────────┤
│  范围    │ int16_t│ int16_t│ int16_t│ int16_t│
│          │ ±16384 │ ±16384 │ ±16384 │ ±16384 │
├──────────┼────────┼────────┼────────┼────────┤
│  对应    │  1号   │  2号   │  3号   │  4号   │
│  物理    │  右前  │  左前  │  左后  │  右后  │
└──────────┴────────┴────────┴────────┴────────┘

字节序: 大端 (Big-Endian)
  例: current = 0x1234 → tx_data[0]=0x12, tx_data[1]=0x34
```

#### 升降 0x1FF 帧 (DLC=8, 标准帧)

```
┌──────────┬────────┬──────────────────────────┐
│  Byte    │  0-1   │          2-7             │
├──────────┼────────┼──────────────────────────┤
│  内容    │ 电机5  │        填 0x00           │
│          │ 升降电流│       (保留)             │
├──────────┼────────┼──────────────────────────┤
│  范围    │ int16_t│                          │
│          │ ±16384 │                          │
└──────────┴────────┴──────────────────────────┘
```

### 3.2 反馈帧 (C620 → STM32)

每个电机以 1kHz 频率独立发送反馈帧：

```
┌──────────┬───────────┬──────────┬──────────┬──────────┬────────────┐
│  Byte    │   0-1     │   2-3    │   4-5    │    6     │     7      │
├──────────┼───────────┼──────────┼──────────┼──────────┼────────────┤
│  内容    │ 机械角度   │ 转速 rpm │ 力矩电流  │ 温度 ℃   │   保留     │
│          │ uint16_t  │ int16_t  │ int16_t  │ uint8_t  │            │
├──────────┼───────────┼──────────┼──────────┼──────────┼────────────┤
│  范围    │  0~8191   │  ±????   │  ±16384  │  0~150+  │     -      │
└──────────┴───────────┴──────────┴──────────┴──────────┴────────────┘

字节序: 大端 (Big-Endian)

反馈 ID 对应:
  0x201 → 1号电机 (FR)    0x202 → 2号电机 (FL)
  0x203 → 3号电机 (RL)    0x204 → 4号电机 (RR)
  0x205 → 5号电机 (升降)
```

## 5. 麦轮运动学公式

```
基础公式 (电机转子正方向):
  V_FR =  Vx - Vy - K·Wz    (motor[0], 1号, 右前)
  V_FL =  Vx + Vy + K·Wz    (motor[1], 2号, 左前)
  V_RL = -Vx + Vy - K·Wz    (motor[2], 3号, 左后)
  V_RR = -Vx - Vy + K·Wz    (motor[3], 4号, 右后)

其中 K = Lx + Ly (半轮距 + 半轴距)
```

### 物理安装方向补偿 (`motor_dir[]`)

由于左右电机镜像安装导致物理"正转"方向相反，运动学中加入了方向系数：

```c
const float motor_dir[4] = {1.0f, -1.0f, 1.0f, 1.0f};
//                           FR     FL     RL     RR
//                          1号    2号    3号    4号

实际输出 = motor_dir[i] × 基础公式
```

| 电机 | motor_dir | 原因 |
|:----:|:---------:|:-----|
| 1号 FR | +1.0 | 基准方向 |
| 2号 FL | **−1.0** | 与1号镜像安装，电机翻转180° |
| 3号 RL | +1.0 | 待实车验证 |
| 4号 RR | +1.0 | 待实车验证 |

### 纯前进时 (Vx > 0, Vy = 0, Wz = 0) — 补偿后:

```
motor[0] FR = +1.0 × (+Vx) = +Vx  ▸ 电机正转 → 轮子前进 ✓
motor[1] FL = -1.0 × (+Vx) = -Vx  ▸ 电机反转 → 轮子前进 ✓ (翻转安装,取反后正确)
motor[2] RL = +1.0 × (-Vx) = -Vx  ▸ 电机反转 → 轮子前进 ?
motor[3] RR = +1.0 × (-Vx) = -Vx  ▸ 电机反转 → 轮子前进 ?
```

> **实车验证**: 推前进摇杆，观察四轮转向是否一致。若某轮反向，将对应 `motor_dir[i]` 取反即可。

## 7. 快速排查清单

| 检查项 | 正确状态 | 如何验证 |
|:-------|:---------|:---------|
| 电调 DIP ID 不重复 | 底盘 1/2/3/4, 升降 5 | 逐一上电，用 CAN 分析仪看反馈 ID |
| 1号对应右前轮 | DIP=1 的电调物理装在右前 | 单发 0x200 前2字节非零值，看哪个轮子转 |
| CAN 终端电阻 | 总线两端各 120Ω | 万用表断电测 CANH-CANL ≈ 60Ω |
| 电机相线顺序 | 三相线颜色对应 | 交换任意两相可反转方向 |
| 反馈帧正常到达 | `g_motor.rx_count[i]` 持续增长 | 用 printf/VoFA 观察 |
